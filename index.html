Academic Project · Capstone

SENYASK: A Filipino Sign Language Recognition & Learning Web App

Capstone Project B.S. Information Technology Lead Developer May – Nov 2026

Project Overview

SENYASK turns a webcam into a Filipino Sign Language (FSL) interpreter and tutor. It recognizes alphabet letters, numbers, words, and phrases in real time, composes the signed words into natural sentences in English, Filipino, and Ilocano, and teaches FSL through tutorials, camera-checked practice, quizzes, and conversation challenges. Built as a two-person capstone at STI College Baguio, where I led development of the AI recognition pipeline.

Objectives

  • Recognize FSL signs from an ordinary webcam or phone camera
  • Translate sign sequences into readable sentences in three languages
  • Make learning FSL interactive with instant camera feedback
  • Keep recognition private and fast by running it in the browser
  • Work reliably across desktops and mobile devices

Tools & Technologies

ReactViteJavaScript PythonMediaPipescikit-learn FirebaseCloudflare WorkersGemini API

Key Highlights

  • Extra Trees classifier on a 141-value feature vector from MediaPipe landmarks
  • Recognition runs fully in the browser, with no prediction server
  • Feature extraction mirrored in Python and JavaScript, cross-checked for identical output
  • Smart Sentence via a Gemini proxy, with an offline rule-based fallback
  • Passed the capstone final defense (November 2026)

What I Learned

SENYASK taught me to take machine learning from a training notebook all the way into a product people use, handling messy real-world input like different signers, cameras, and screen shapes. I learned to design fallbacks so the app keeps working when a service is slow, and to make decisions based on testing rather than guesses.

This project shows my ability to turn applied machine learning into an accessible, real-world tool.
